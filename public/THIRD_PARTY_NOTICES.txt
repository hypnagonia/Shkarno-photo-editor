Shkarno — third-party components
==========================================

All processing runs locally in the browser. Model weights are served from this
site and cached on the device; photographs are never uploaded.

LibRaw 0.22.2 (compiled to WebAssembly, unpack-only wrapper)
  https://www.libraw.org — dual licensed LGPL-2.1 / CDDL-1.0 (used under LGPL-2.1).
  Build script and wrapper source: native/libraw/ in this project; the module can
  be rebuilt/relinked from those sources.

libheif (libheif-js 1.23.2, WebAssembly) — HEIC fallback decoder
  https://github.com/strukturag/libheif — LGPL-3.0 (includes libde265, LGPL-3.0).

ONNX Runtime Web 1.30 — MIT License, Copyright (c) Microsoft Corporation.

Swin2SR lightweight ×2 (optional 2× upscale) — Apache License 2.0
  Marcos V. Conde et al., "Swin2SR: SwinV2 Transformer for Compressed Image
  Super-Resolution and Restoration", ECCV Workshops 2022. https://github.com/mv-lab/swin2sr
  Weights: https://huggingface.co/caidas/swin2SR-lightweight-x2-64 (ONNX export:
  https://huggingface.co/Xenova/swin2SR-lightweight-x2-64); fixed-size, folded
  graph produced by scripts/models/swin2sr.py.

SegFormer-B0 (ADE20K 512×512) — NVIDIA Source Code License for SegFormer
  Enze Xie et al., "SegFormer", NeurIPS 2021. https://github.com/NVlabs/SegFormer
  ONNX conversion: https://huggingface.co/Xenova/segformer-b0-finetuned-ade-512-512
  NOTE: the SegFormer license permits NON-COMMERCIAL (research/evaluation) use only.
  A commercial deployment must replace this model or obtain a license from NVIDIA.

MobileSAM (tap-to-select masks) — Apache License 2.0
  Chaoning Zhang et al., "Faster Segment Anything: Towards Lightweight SAM for Mobile
  Applications", 2023. https://github.com/ChaoningZhang/MobileSAM
  With the mask decoder of Segment Anything (Kirillov et al., 2023, Apache License 2.0,
  https://github.com/facebookresearch/segment-anything).
  ONNX export: https://huggingface.co/Acly/MobileSAM (MIT).

Depth Anything V2 Small — Apache License 2.0
  Lihe Yang et al., "Depth Anything V2", 2024. https://github.com/DepthAnything/Depth-Anything-V2
  ONNX conversion: https://huggingface.co/onnx-community/depth-anything-v2-small
